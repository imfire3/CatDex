# CatDex — Textes App Store / Play (FR)

## Nom
CatDex

## Sous-titre (30 car. max iOS)
Ton quartier. Tes chats.

## Description courte (Play, 80 car.)
Capture les chats de ton quartier, analyse-les à l’IA, construis ton CatDex.

## Description longue

CatDex transforme tes rencontres félines en collection.

Marche dans ton quartier, scanne un chat avec la caméra, laisse l’IA proposer une fiche, puis place-le sur la carte. Retrouve toute ta collection dans le CatDex, suis ta progression, et explore autour de toi.

Fonctionnalités :
• Scanner photo + analyse assistée par IA
• Carte des chats que tu as découverts
• CatDex personnel synchronisé
• Compte sécurisé (e-mail)

CatDex est en bêta : certaines alertes et missions avancées arrivent bientôt.
